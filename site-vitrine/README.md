# Site vitrine — Axion Studio

Site vitrine statique (HTML / CSS / JS, sans dépendance) de la micro-entreprise **axionstudio**
(Arthur Champagne-Forterre, EI) : automatisation des processus, IA pour entreprises, création de sites web.

Ouvrir `index.html` dans un navigateur suffit. Destiné au domaine `axionstudio.fr`.

## À compléter avant la mise en ligne
- **SIRET** : remplacer « En cours d'attribution » (section Mentions légales) dès réception de l'avis INSEE.
- **Hébergeur** : nom, adresse et téléphone (obligatoire, section Mentions légales).
- **Adresse** : seule la commune est affichée. La loi (LCEN) demande l'adresse de l'éditeur ;
  ajoutez-la ou utilisez une domiciliation si vous ne voulez pas publier votre adresse personnelle.

## Personnaliser
- Textes : `index.html` · Couleurs : variables en haut de `style.css` · Adresse du formulaire : `script.js`.
