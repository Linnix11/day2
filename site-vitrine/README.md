# Site vitrine — Atelier Brindille (exemple)

Site vitrine statique (HTML / CSS / JS, sans dépendance) pour une micro-entreprise fictive de menuiserie.

Ouvrir `index.html` dans un navigateur suffit.

## Personnaliser
- Nom, coordonnées, SIRET : `index.html` (sections « Contact » et pied de page).
- Couleurs : variables en haut de `style.css`.
- Photos : remplacer les blocs `.work` de la section « Réalisations » par des `<img>`.
- Adresse de réception du formulaire : `script.js` (lien `mailto:`).
